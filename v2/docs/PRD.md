# OneVoice v2 - Product Requirements Document (PRD)

**버전**: 2.0  
**작성일**: 2024년 4월  
**상태**: Active Development

---

## 1. 제품 비전

**"언어 장벽 없는 실시간 대면 소통"**

전문 통역사의 도움 없이도 서로 다른 언어를 사용하는 두 사람이 마주 앉아 자연스럽게 대화하고, 실시간으로 상대방 언어로 번역된 내용을 받을 수 있는 웹 기반 동시통역 솔루션.

---

## 2. 사용자 페르소나

### 페르소나 1: 비즈니스 미팅 참가자 (민준, 35세)
- **배경**: 한국 IT 회사의 영업 담당자
- **목표**: 일본 파트너사와의 화상 미팅에서 자연스러운 소통
- **pain point**: 통역사 비용 부담, 미팅 효율성 저하
- **해결**: OneVoice로 실시간 번역 받으며 1:1 대면 회의

### 페르소나 2: 여행자/관광객 (앨리스, 28세)
- **배경**: 미국 관광객이 서울 여행 중
- **목표**: 카페, 식당, 명소에서 현지인과 자연스럽게 대화
- **pain point**: 번역기 사용이 어색함, 문화 차이 이해 부족
- **해결**: 스마트폰으로 Knowledge Guide를 통해 예절 조언 받고 실시간 번역

### 페르소나 3: 의료 현장 의사소통 (의사 李, 50세)
- **배경**: 중국 환자를 진료하는 한국 의사
- **목표**: 환자 증상 청취 및 진료 설명
- **pain point**: 정확한 의료 용어 번역 필수, 느린 번역
- **해결**: 2~5초 지연의 고속 동시통역으로 신뢰할 수 있는 의료 소통

## 3. 핵심 가치 제안

| 가치 | 설명 |
|------|------|
| **속도** | 2~5초 지연의 실시간 동시통역 (전문 통역사 3초 평균) |
| **비용** | 월 1,000분 기준 $23 이하 (통역사 시간당 $30~100과 비교) |
| **접근성** | 웹 기반, 추가 설치 불필요, 마이크만 있으면 사용 가능 |
| **자연성** | 이중 패널 UI로 대면 상황 구현 (부자연스러운 번역기 아님) |
| **지원** | Knowledge Guide로 문화 예절, 언어 팁 제공 |

## 8. 기술 결정 사항

### 왜 Gemini Live API인가?

1. **지연시간**: REST API 대비 3배 빠름 (WebSocket 직결)
2. **오디오 처리**: PCM 스트리밍으로 네이티브 지원
3. **비용 효율**: 분 단위 정가, 트래픽 기반 아님
4. **다국어**: 7개 언어 네이티브 지원
5. **음성 출력**: 오디오 응답으로 리스닝 구현

### 왜 프론트엔드 전용인가?

1. **배포 단순**: 정적 호스팅 (Vercel, Netlify)
2. **운영 비용 제로**: 서버 관리 불필요
3. **확장성**: 자동 스케일링 (CDN)
4. **API 키 보안**: 클라이언트 사이드 주의 (이후 백엔드 추가 예정)

| 동시성 버그 (WebSocket) | 중 | 중 | Stress 테스트, 재연결 로직 |

## 10. 정책 및 준수

### 개인정보보호
- **PII 필터**: 주민등록번호, 카드번호, 이메일 자동 마스킹
- **API 전송**: 마스킹된 데이터만 Gemini API로 전송
- **localStorage**: 사용자 단말에만 저장 (클라우드 백업 없음)

### 이용약관
- 비상업적 목적: 무료
- 상업적 목적: 향후 라이선스 정책

### 데이터 보안
- HTTPS 필수
- API 키는 환경 변수로 관리
- localStorage는 서버에 전송 안 함
